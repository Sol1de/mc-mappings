# Target configurations

The following configurations are targeted for **each of Minecraft 1.21 and 1.21.11**:

- **Standard / Vanilla** — client release listed in the [Mojang version descriptors](versions.md).
- **Standard / Fabric** — combinations declared by [Fabric Meta](references.md#standard-launcher).
- **Standard / Forge** — distributions identified in the [Forge catalog](references.md#standard-launcher).
- **Lunar** — module without Fabric, offered according to the [user's launcher report](references.md#lunar).
- **Lunar + Fabric** — Fabric module offered according to the [same report](references.md#lunar).

This represents ten target configurations. Lunar/Forge is not included: the user's report lists no Forge module for these versions. The Lunar module without Fabric is not treated as the standard Vanilla binary.

This list describes the intended coverage, not its implementation status. Tickets and issues track table creation and validation. The [references](references.md) describe known builds and the limitations of the evidence.
